I'm a **Software Engineer** and **Full Stack Developer** specializing in the **MERN stack**, passionate about building scalable web applications and real-world digital solutions. I combine strong technical skills with a product mindset to deliver systems that are both robust and user-friendly.

I completed my **BS in Software Engineering from NUML Islamabad** and gained hands-on government-sector experience through an internship at **NEPRA** (National Electric Power Regulatory Authority), where I built a live IT Asset Control System still in use today.

## 📋 Key Projects

---

### 🏛️ IT Asset Control System (IACS)
**Government Internship Project @ NEPRA** · *Currently live within the organization*

A web-based IT asset inventory and tracking system built during my internship at the National Electric Power Regulatory Authority.

**Features:**
- Asset tracking, assignment & transfer management
- Repair & maintenance logs
- Admin roles & access control
- Dashboard with real-time overview
- Notification system

**Technologies:** React • Python Flask • MySQL

---

### 🍽️ Spice Hut — Restaurant Ordering Platform
**Freelance Team Project** · *Canadian Indian Restaurant Chain*

A full-featured multi-branch food ordering platform. I handled the complete user-side (frontend + backend) in MERN; collaborating teammate built the admin side.

**Features:**
- Multi-branch support
- Dynamic menu browsing
- Cart & order management
- Seamless user experience

**Technologies:** MongoDB • Express • React • Node.js

---

### 👗 SEYA Fashion — E-Commerce Platform
**Solo Freelance Project** · *Ladies Fashion Brand*

A full MERN rebuild of a ladies' fashion e-commerce website (previously on WordPress), delivering a custom, scalable solution.

**Features:**
- Product browsing & filtering
- Standard & custom sizing selection
- Delivery management
- Admin panel for inventory & orders

**Technologies:** MongoDB • Express • React • Node.js

---

### 🎮 Gaming Through Voice Recognition
**Final Year Project (FYP) + Freelance Extension**

A Windows application enabling upper-limb disabled users to launch and control games entirely through voice commands — making gaming accessible for everyone.

**Planned Extensions:**
- Shouting-intensity controls
- Eye-tracking game modules

**Technologies:** Python • Voice Recognition • SQL Server

---

### 🤖 AI Study Buddy for Coding
**Concept Stage Project**

An interactive, humanized coding education tool designed to make learning to code more engaging and personalized — combining AI with step-by-step guidance.
